# Кулинарная книга (Recipe Book)

Приложение для ведения личной коллекции кулинарных рецептов.

Семестровый проект по дисциплине «Лабораторный практикум: Практический курс веб-разработки (React, TypeScript, Node и Supabase)».

- **Автор:** Иван Химич
- **Группа:** 24ПИ2

---

## О проекте

Приложение помогает сохранять и просматривать персональные рецепты блюд. На данном этапе реализована навигация между страницами, список рецептов, подробный просмотр выбранного рецепта и экран добавления.

---

## Стек технологий

- React 19
- TypeScript
- React Router
- Vite

---

## Страницы приложения

- `/` — перенаправление на `/recipes`
- `/recipes` — список всех рецептов
- `/recipes/:id` — страница просмотра рецепта (например, `/recipes/r1`)
- `/recipes/new` — страница создания рецепта
- `*` — страница 404 (неизвестный адрес)

> **Примечание:** Все записи в текущей версии являются демонстрационными и хранятся в файле `src/data/recipes.ts`.
