# Кулинарная книга (Recipe Book)

Приложение для ведения личной коллекции кулинарных рецептов, планирования меню и управления списком ингредиентов.

Семестровый проект по дисциплине «Лабораторный практикум: Практический курс веб-разработки (React, TypeScript, Node и Supabase)».

---

## О проекте и сценарий использования

Кулинарная книга помогает пользователю сохранять и структурировать персональные рецепты блюд. Пользователь создаёт карточки рецептов, указывает перечень ингредиентов и пошаговые инструкции приготовления, распределяет блюда по категориям кухонь и находит нужные рецепты с помощью поиска и фильтрации. В последующих лабораторных работах проект будет дополнен расчётом КБЖУ, серверной аналитикой и синхронизацией данных через облачную БД.

---

## Стек технологий

- **Фронтенд:** React 19 / 18, TypeScript, Vite, CSS3
- **Окружение:** Node.js (версия указана в файле `.node-version`), npm
- **В следующих этапах:** React Router, Supabase (PostgreSQL + Auth), Node.js (Express / Fastify REST API)

---

## Требования к окружению

- **Node.js:** `22.22.1` (см. файл `.node-version`)
- **npm:** `9.2.0` или новее
- **Git:** современная версия

## Запуск проекта

Из корня скачанного / клонированного проекта:

```bash
cd frontend
npm ci
npm run dev
```

После выполнения команды в терминале отобразится адрес локального сервера (обычно `http://localhost:5173/`). Откройте его в браузере.

---

## Проверка сборки и типов

Остановите dev-сервер сочетанием клавиш `Ctrl+C`. Затем выполните в каталоге `frontend`:

```bash
npm run build
npm run preview
```

Команда `npm run build` выполняет строгую проверку типов (`tsc -b`) и компилирует оптимизированную production-сборку в директорию `frontend/dist`. Команда `npm run preview` позволяет запустить и проверить собранную версию локально.
