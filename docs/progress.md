## Лабораторная работа №2: Страницы приложения и навигация

### Результат этапа
- Установлен и подключён пакет `react-router`.
- Описаны типы сущности рецепта (`Recipe`, `RecipeCategory`, `RecipeDifficulty`) в `src/types/recipe.ts`.
- Добавлен массив из 5 демонстрационных рецептов в `src/data/recipes.ts`.
- Выделен переиспользуемый компонент карточки `RecipeCard` с типизированными props.
- Созданы компоненты страниц:
  - `RecipesPage` — список рецептов (с сообщением «Рецептов пока нет.» при пустом массиве);
  - `RecipeDetailsPage` — просмотр карточки рецепта по id из URL;
  - `NewRecipePage` — заглушка создания рецепта;
  - `NotFoundPage` — страница 404 для неизвестных маршрутов.
- Реализован общий макет `AppLayout` с шапкой, навигацией через `NavLink` и `Outlet`.
- Подключён `BrowserRouter` в `main.tsx` и настроены вложенные маршруты в `App.tsx` (включая редирект с `/` на `/recipes`).
- Настроены стили: адаптивная сетка через CSS Grid, выделение активного пункта навигации, доступность и читаемость на узких экранах (360px).
- Настроена раздельная обработка несуществующей страницы (404) и отсутствующей записи по id (`/recipes/missing`).

### Адреса страниц
- `/` — перенаправление на `/recipes`
- `/recipes` — список рецептов
- `/recipes/:id` — страница выбранного рецепта
- `/recipes/new` — страница создания рецепта
- `*` — страница 404

### Шаги проверки
1. Выполнить `npm run dev` в папке `frontend`.
2. Открыть `/` — происходит перенаправление на `/recipes` и отображается список из 5 рецептов.
3. Открыть две разные карточки (например, `/recipes/r1` и `/recipes/r2`) — отображаются разные данные.
4. Открыть `/recipes/r1` в новой вкладке и обновить страницу — карточка открывается и работает после обновления.
5. Открыть `/recipes/new` — отображается заголовок, навигация и текст заглушки.
6. Открыть `/unknown` — отображается страница 404 («Страница не найдена»).
7. Открыть `/recipes/missing` — отображается сообщение о том, что рецепт не найден.
8. Проверить пустой список (временно очистить массив `recipes`) — выводится сообщение «Рецептов пока нет.».
9. Проверить навигацию через Tab/Enter и отображение при ширине 360px — верстка читаема, горизонтальной полосы прокрутки нет.
10. Выполнить `npm run build` и `npm run preview` — сборка и запуск проходят без ошибок.
