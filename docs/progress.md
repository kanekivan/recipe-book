# Отчёт о прогрессе разработки: Лабораторная работа №1

## Результат этапа
- Подготовлен каркас проекта «Кулинарная книга» (Recipe Book) на основе шаблона React + TypeScript + Vite.
- Реализован начальный экран со строгой типизацией заголовка, кратким описанием темы и разделом-заглушкой «Мои рецепты».

## Шаги проверки проекта

1. **Проверка установки зависимостей:**
   В каталоге `frontend` зависимости корректно устанавливаются через чистую установку `npm ci` (или `npm install`), создаётся валидный `package-lock.json`.

2. **Проверка запуска сервера разработки:**
   Команда `npm run dev` запускает локальный dev-сервер Vite (на порту `5173`). Страница успешно открывается в браузере без ошибок в DevTools Console и терминале.

3. **Проверка работы HMR и содержимого страницы:**
   Приложение отображает заголовок «Кулинарная книга», подзаголовок с описанием и блок с заглушкой «Здесь появится список ваших рецептов.».

4. **Проверка строгой типизации TypeScript:**
   В конфигурации `tsconfig.app.json` активен параметр `"strict": true`. При попытке присвоения переменной `appTitle` значения другого типа (например, `number`) вызов `npm run build` завершается ошибкой `error TS2322: Type 'number' is not assignable to type 'string'`.

5. **Проверка production-сборки:**
   Команда `npm run build` выполняет проверку типов `tsc -b` и собирает production-артефакты в `frontend/dist` без предупреждений и ошибок.

6. **Проверка локального предпросмотра сборки:**
   Команда `npm run preview` раздаёт собранный бандл из каталога `dist/` и подтверждает готовность клиентской части.
